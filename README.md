# Shmsan Views
يسحب منشورات قناة `@shmsannews` ويرسل طلب مشاهدة لرابط واحد من الطابور في كل تشغيل، عبر نموذج الموقع باستخدام Playwright.

## الإعداد
أضف أسرار تسجيل الدخول للموقع من Settings > Secrets and variables > Actions:
- `SITE_USERNAME` — اسم المستخدم
- `SITE_PASSWORD` — كلمة المرور

تشغيل رئيسي يدوي: Actions > Shmsan Views > Run workflow.
إعادة محاولة رابط محدد: Actions > Shmsan Views - Manual Link Retry > Run workflow؛ كل محاولة تطلب 100 مشاهدة مدفوعة.

## كيف يعمل
- أول تشغيل: يضيف أحدث منشور فقط إلى الطابور.
- بعدها: يضيف كل المنشورات الجديدة بالترتيب، ويعالج الأقدم أولاً.
- يجرّب حتى ثلاثة روابط في التشغيل؛ بعد ثلاث إخفاقات يتخطى الرابط نهائياً.
- يحفظ الطابور والروابط المعالجة والمنفذة وعدّاد الإخفاقات في `state/`.
- لا يُسجّل الرابط كمنفذ إلا بعد ظهور تأكيد نجاح الطلب.

## تصفير الحالة
احذف الملفات داخل مجلد `state/` (ما عدا `.gitkeep`) لبدء من الصفر.
